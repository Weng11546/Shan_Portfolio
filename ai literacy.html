Reflection

What did AI help me accomplish?

  • Planned the ExpenseFlow database and screens faster.
  • Understood error messages and found likely causes sooner.
  • Drafted SQL queries and CSS that I then tested and refined.
  • Improved the wording and grammar of my written content.

What did I personally verify?

  • Ran and tested all code on a real emulator or browser.
  • Checked SQL totals against the original data.
  • Confirmed technical facts with official documentation such as Android docs and OWASP.
  • Made sure every description matched the work I actually did.

What did I learn from using AI?

  • Clear, specific prompts with context give much better answers.
  • AI is a helper for ideas and explanations, not a replacement for understanding.
  • Asking AI to explain its answer helped me learn the concept, not just copy the result.
  • I remain responsible for the final work I submit.

What limitations or errors did I discover?

  • Some code looked correct but failed when I ran it or used outdated methods.
  • One SQL query grouped results incorrectly and gave wrong totals.
  • AI sometimes sounded confident while being wrong, so I could not trust it without checking.
  • It did not know the details of my project unless I explained them, so some suggestions did not fit.

Responsible AI use

I use AI as a support tool. I review and test its output, check facts against reliable sources, avoid sharing private or sensitive data in prompts, and write my final work in my own words so that it truthfully reflects my skills.
